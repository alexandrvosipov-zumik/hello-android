# Требования: hello-android

## Цель
Создать простое устанавливаемое Android-приложение на React Native CLI и TypeScript.

## Функциональные требования
- При запуске показывать один экран.
- В центре экрана отображать текст «Привет, мир!».
- Не требовать подключения к интернету или авторизации.

## Критерии готовности
- Android-проект и JS-зависимости созданы совместимым React Native CLI.
- Приложение запускается на Android без ошибки.
- GitHub Actions успешно собирает debug APK и загружает artifact.
